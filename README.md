# BLACK BAT

A lightweight Persian-language street-driving game prototype built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a modern web browser. No build step or package installation is required.

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Extract this ZIP file.
3. Upload `index.html`, `README.md`, and `.nojekyll` to the repository root (or upload the extracted folder contents).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The published URL will appear in the Pages settings.

## Notes

- The game uses browser JavaScript and the HTML Canvas API; no external framework is required.
- Vehicle photos are loaded from third-party image hosts, so an internet connection is needed for those photos to appear. Those hosts may change or block hotlinking over time.
- Player progress is stored in the browser's local storage and is specific to that browser/device.
- This is a web prototype, not an Android APK.
